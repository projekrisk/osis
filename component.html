7. Responsive Bottom-Sheet Modal & Toast Notification

8. Prompt Referensi untuk Agen AI

Buatkan tampilan antarmuka web dashboard / halaman CRUD dengan mengacu sepenuhnya pada file `desain/component.html` sebagai Design System & UI Reference:
1. Gunakan font "Bricolage Grotesque" (sans) dan monospace untuk kode/angka dengan `.tnum` (`tabular-nums`), serta palet warna `notion` (`bg: #ffffff`, `sidebar: #f7f7f5`, `hover: #efefed`, `text: #222222`, `gray: #666666`, `border: #e5e5e5`, `blue: #2563eb`, `red: #e03e3e`, `redBg: #fbdbdc`).
2. Gunakan App Shell dengan sidebar `285px` yang memiliki transisi halus ke mode mini-rail ikon saja (`68px`, `.sidebar-collapsed`) lewat tombol ikon `panel-left` di sebelah breadcrumb header, serta drawer overlay di mobile.
3. Setiap halaman diawali Page Header bergaya dokumen (ikon Lucide `w-12 h-12`, judul `text-3xl font-bold tracking-tight`, dan deskripsi formal singkat `text-sm text-notion-gray`).
4. Toolbar tabel harus rata penuh (justify): input pencarian `flex-1`, filter dropdown `select.modern-select` (auto-search jika > 3 opsi), tombol Filter, dan tombol aksi utama di kanan.
5. Setiap tabel wajib responsif: tampil sebagai `` di desktop (`hidden md:block`) dan otomatis berubah menjadi accordion collapse single-open (`toggleMobileRow`) di layar mobile (`md:hidden`).
6. Gunakan komponen `input.modern-file` untuk upload file, tombol toggle lihat/sembunyikan pada semua input password, tab horizontal scrollable (`flex-nowrap overflow-x-auto whitespace-nowrap`), modal bottom-sheet responsif (`openAppModal` / `closeAppModal`), serta notifikasi toast (`showToast`).
